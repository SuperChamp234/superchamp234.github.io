Experiences

  • Compiler Engineer at Qualcomm India Private Limited
    C/C++, picolibc, LLVM libc++, compiler-rt, Hexagon assembly, Linker/Loader internals April 2026 – Present

    • Added Hexagon architecture support to picolibc and migrated the Hexagon C/C++ runtime from Dinkumware to picolibc + LLVM libc++ across 3 platforms (compute DSP, internal RTOS, hypervisor), porting legacy platform code and handling each environment’s OS- and hypervisor-specific integration.

    • Extended NetBSD’s RTLD into an ELF dynamic loader for picolibc (Linux and Hexagon hypervisor), redesigned around a single libc embedded in the loader so every loaded object shares one libc instance per process.

    • Benchmarked Hexagon’s compiler-rt builtins to identify performance gaps, then reworked 5 builtins to use Hexagon’s co-processors and UserDMA, improving data throughput by 1.5–2x and yielding about a 7% improvement in MLIR-generated code using these builtins.

  • Design Verification Engineer at Incore Semiconductors
    eUVM (D), Bluespec SystemVerilog, RISC-V, Spike, riscv-dv, Verilator, Questa, Python Aug 2025 – Mar 2026

    • Built the full verification environment for Dolomite, a dual-issue superscalar RV64 core, from scratch in eUVM (UVM in D): agents, sequences and scoreboards, checked against Spike and wired to bsc-generated Verilog. Verified hazard handling and pipeline control (stalls, flushes, issue-slot interactions).

    • Co-designed the supervisor-mode verification environment for Calcite, an RV32IMAC core: privilege transitions, traps and interrupts, CSRs, PMP, page-table walks and the TLB. Developed constrained-random generation of self-terminating programs exercising privilege transitions, while also extending riscv-dv.

    • Verified implementation-specific microarchitectural behavior the ISA leaves open, such as TLB handling of page-protection changes without a flush, plus CSR, PMP and interrupt corner cases.

    • Built the Python tooling for Azurite, an RV32IM core: test generation, run orchestration, log and coverage analysis, and CI integration across riscv-tests and riscv-dv.

  • Hardware Acceleration Intern at Acceleration Robotics
    C++/C, Vitis HLS, Vivado, KV260, Kria Robotics Stack January 2024 - June 2024

    • Accelerated ROS2 workloads by optimizing Adaptive Monte-Carlo Localization (AMCL).

    • Designed and deployed a ROS2 node with a kernel for an accelerated particle filter algorithm on the KV260 platform.

    • Developed a custom KV260 platform in Vivado for HLS kernel deployment, achieving a 1.95x speedup over the onboard SoC’s CPU.

    • Validated with a Cocotb/pytest regression suite (exhaustive decoder and ALU unit tests, hazard and memory tests) and set up CI with a Verilator + RISC-V toolchain devcontainer.
